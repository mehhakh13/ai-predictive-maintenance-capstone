# Predictive Maintenance Dashboard - Frontend

A modern React-based dashboard for predictive maintenance risk analysis with a focus on the System Risk Heatmap feature.

## Installation

```bash
cd ai-predictive-maintenance-capstone/frontend
npm install
npm run dev
```

The app will be available at `http://localhost:5173`

## Features Implemented

- ✅ System Risk Heatmap Dashboard (complete)
- ✅ Home Page with navigation
- ✅ Interactive heatmap with tooltips and click details
- ✅ KPI cards, insights panel, and charts
- ✅ Dark theme with responsive design
- ✅ Mock data (ready for backend integration)

## Data Integration

Update `src/hooks/useRiskHeatmapData.js` to switch from mock data to real CSV/API data.

See full documentation inside the file.
