   mkdir -p ai-predictive-maintenance-capstone/frontend/public/data
   cp data/dashboard/ml_heatmap.csv \
      ai-predictive-maintenance-capstone/frontend/public/data/
   cp data/dashboard/historical_heatmap.csv \
      ai-predictive-maintenance-capstone/frontend/public/data/

3. Update src/hooks/useRiskHeatmapData.js:
   Replace mock data section with:
   
   const mlResponse = await fetch('/data/ml_heatmap.csv');
   const mlText = await mlResponse.text();
   const mlData = parseCSV(mlText);
   
   const histResponse = await fetch('/data/historical_heatmap.csv');
   const histText = await histResponse.text();
   const histData = parseCSV(histText);
   
   setMlHeatmap(mlData);
   setHistoricalHeatmap(histData);

🆘 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"npm: command not found"
  → Install Node.js from nodejs.org

"Port 5173 already in use"
  → Kill existing process: lsof -ti:5173 | xargs kill -9
  → Or use different port: npm run dev -- --port 3000

"Module not found" errors
  → Delete node_modules and package-lock.json
  → Run npm install again

Blank page
  → Check browser console for errors
  → Verify React DevTools shows components
